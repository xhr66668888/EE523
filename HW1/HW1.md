Homework Assignment 1 

 

Objective:

The goal of this assignment is to get familiar with Kotlin and to practice setting up a development

environment, creating a simple ToDoList app, and exploring the basic components in Kotlin.

 

Getting Started:

Set up a development environment by installing Android Studio, and the necessary tools and
Plugins.

Android Studio SetUp: https://developer.android.com/studio

Create a Simple app in Kotlin by following these steps:
Create a new Kotlin project using the Android Studio.
Android Studio -> File -> New -> New Project -> Basic Views Activity
Change the Name of your Application to “ToDoList”
Run the app on an emulator or physical device to make sure it works properly.
 

Main Goal:

Explore the basic components in Kotlin by creating a simple app that displays a list of items.
The app should have the following features:

A button to add new Task Items to the list.
A button to Remove items from the list.
The ability to display the number of items in the list.
Add Time Deadline to Task Item using Time Picker Dialog.
Add strike through functionality as shown in the video.
 

You can use the following components:
TextInput, Button, RecyclerView, and Text to create the user interface for the app.

Make sure that your application folder contains a README.md file, where you need to describe all these points:

1. Explain the working of your App.

2. How many hours it took you to complete building it.

3. What were the most challenging parts.

4. Mention all the websites and other resources you used to build this App.
