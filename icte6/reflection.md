# ICTE6 - Reflection

Our team built a **Smart Tip Splitter** Android app in Kotlin. The app lets the user enter a bill amount and tax rate, choose a tip percentage, change the number of people, and then calculate the tax amount, tip amount, final total, and per-person split. Figma helped before coding because it gave me a clear layout to follow, including the spacing, colors, rounded input boxes, blue calculate button, and result card. Gemini helped by giving me starter Kotlin logic, explaining the tip/tax formulas, suggesting `ConstraintLayout` for the UI, and showing how to validate `EditText` input. Gemini's mistakes were that its first code was too basic, did not fully match the Figma screen, and did not include enough input validation. I had to modify the code, test the formulas, add error handling, and clean up the XML layout. Next, I would improve the app by making the layout more responsive for different screen sizes and maybe adding a custom tip input instead of only fixed percentage buttons.
